# MUN Delegate Management Portal

## Overview

The MUN Delegate Management Portal is a web-based platform designed to streamline delegate registration and conference management for Model United Nations events.

This project is inspired by my experience in External Relations for AUSMUN, where delegate communication, registration, and participant support are essential to creating a professional conference experience.

## Features

### Planned Features

- Delegate registration form
- Admin dashboard for viewing registered delegates
- Committee allocation system
- Role-based access for delegates and administrators
- Secure login and authentication
- Centralized database for participant information
- Search and filter functionality for delegate records

## Technologies

### Planned Technologies

- Python
- FastAPI or Flask
- HTML

- SQL

## Project Goals

The goal of this project is to apply backend development concepts to a real-world event management problem by building a system that improves organization, accessibility, and efficiency.

This project will help demonstrate skills in:

- Backend development
- Database management
- Web application structure
- Authentication
- CRUD operations
- User interface design
- Real-world problem solving
